# John Loyd Cabral | System Administrator Portfolio

Stack: HTML5, CSS3, vanilla JavaScript. No build step, no database.

## Run the portfolio
Open `index.html` in a browser, or serve this folder with VS Code Live Server.
The profile photo is `images 984.jpg` in the project root.

## Files
- `index.html` Home, Roles, Skills, Tools, Linux Terminal, About
- `style.css` Responsive fire-inspired theme and layout
- `fire.js` Flame, ember and smoke background
- `translations.js` English / Filipino text
- `terminal.js` Simulated Linux command prompt
- `main.js` Translation, navigation, cards, and interaction effects
